# Private Update Inbox

Use `2026-raw-updates.md` as a private scratchpad for messy future portfolio notes.

Rough writing is expected. You can paste fragments, bullets, links, screenshots to add later, half-remembered context, and incomplete notes. Dates, links, tags, collaborators, locations, organizations, and media are optional at capture time.

Good things to paste here:

- Presented a workshop on robotics.
- Joined a mentorship program.
- Published, drafted, submitted, or revised a paper.
- Attended or helped organize a conference.
- Started a prototype.
- Met with an advisor, collaborator, or review group.
- Wrote a field note or technical observation.
- Added a new affiliation.
- Gave a talk.
- Shared a LinkedIn post.
- Built a tool.
- Tested a robot, facade, spatial computing workflow, simulation, interface, or AI-assisted design process.
- Added a new project image, diagram, video, code link, or research artifact.

## Publication Rules

- Nothing from the inbox should render publicly.
- Nothing from the inbox should be published without review.
- Codex should later classify notes into the correct content type, rewrite them in the portfolio voice, and move only reviewed material into `content/staged/` or `content/published/`.
- If a fact is missing, Codex should leave the field blank, use `null`, or ask for clarification. It should not invent dates, achievements, affiliations, collaborators, outcomes, metrics, or links.

## Privacy Note

This repository is a static website. Files committed and deployed may be publicly reachable even if they are not linked from the site. Raw inbox note files are ignored by `.gitignore` by default, but still review before publishing or deploying.
